# FlowFrame 1.1.2

FlowFrame 1.1.2 是当前推荐的稳定版本，适用于 Android 7.0 及以上的 `arm64-v8a` 设备。

## 本版改进

- 修复正式包中解析组件被代码压缩错误裁剪、导致所有平台都提示解析失败的问题。
- 抖音公开视频、抖音图文和哔哩哔哩公开视频均已在 Android 16 arm64 实体设备完成解析回归。
- 任务卡片右上角改为真正的操作菜单：完成/失败任务可“删除记录”，进行中任务可“取消任务”。
- 删除记录前会二次确认；删除只移除 FlowFrame 历史，不会删除已经保存到相册或媒体库的文件。
- 包含 1.1.0 的链接自动净化、竖屏 1080 档选择和抖音图文图片/音频/MP4 三种输出。

安装 `FlowFrame-1.1.2-arm64-release.apk`。

APK SHA-256：

```text
596F32F6E48A28976074129101CD002FBCC8C6F461629E742B73B86F5805DC24
```

正式包已通过 APK Signature Scheme v2/v3 和 16 KiB ZIP 对齐验证。完整改动见仓库根目录的 `CHANGELOG.md`。

FlowFrame 仅支持无需登录的公开内容。请只保存你本人创作、已获授权或依法有权保存的媒体。
