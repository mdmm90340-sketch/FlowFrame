# 视频与图集下载 · 流影 1.2.0

这是本地交付版本，版本代码 6。没有创建 GitHub Release、推送提交或上传安装包。

## 可见变化

首页用“视频与图集下载”说明用途，桌面名称为“流影下载”。浅深主题、状态栏、真实图片、图集浏览、宽屏布局与系统返回导航统一调整。

图集可以逐张选择、全选或取消全选，并按作品原始顺序保存为图片或合成 MP4。可用音频单独提供下载选项。格式详情展示真实解析结果，单一画质不再重复出现几个等价按钮。

保存位置使用系统目录选择器；所选目录授权失效后给出重新选择或恢复默认目录的提示。诊断复制、开源许可、关于、媒体打开/分享、任务取消/重试/删除均有实际实现。删除任务记录不会删除已经保存的媒体。

## 稳定性

- 真实网络与 Wi-Fi 策略参与队列控制，传输速度与字节来自下载器回调。
- 任务完成、失败、取消为终态，旧回调不能覆盖；发布回滚与完成提交处理取消竞争。
- 历史文件在后台加载、原子保存，普通进度节流写盘；取消和完成立即保存。损坏文件保留，避免静默覆盖。
- 兼容原有任务字段和设置；分享启动后旋转不再重放旧分享并清空输入。
- 图像按实际 JPEG / PNG / WebP 字节保存，缺图、多视频和混合媒体明确拒绝。

## 平台边界

保留抖音和哔哩哔哩，增加微博、小红书、快手的公开页面适配。只处理无需登录的公开单视频或纯图集。适配器存在不等于所有链接可下载。

微博正式包已完成视频保存、九图中选择两图保存以及 MP4 合成。B 站也完成实际下载与离线/取消/重试。小红书、快手尚缺成功的实际下载验收，保留试验性状态。链接失效、匿名访问限制和站点挑战会明确报告，不导入账号 Cookie。

## 安装与核验

手机安装 `FlowFrame-1.2.0-arm64-release.apk`；`x86_64-test-release` 仅用于电脑虚拟机。默认源码构建仍只生成 arm64-v8a。

应用 ID 保持 `com.flowframe.app`，沿用原正式版签名证书，SHA-256 指纹为：

```text
2ef4b184c1694d1f9813711454c3ea9c15a8d331fe59733e593b78e456f3f0ac
```

APK 文件哈希在随包 `SHA256SUMS.txt` 中；证书指纹与文件哈希含义不同。使用正式签名旧版本时可覆盖升级；签名不同的旧 Debug 包无法直接覆盖。不要为此删除需要保留数据的应用。

本次测试结果见 [验收报告](../VERIFICATION-1.2.0.md)。模拟器通过范围与未完成项目分开列出，不能等同于 arm64 真机验收。

普通 4 KiB 虚拟机与官方实验性 16 KiB x86_64 镜像的正式包原生媒体流程均通过。虽然已重编修复 WebP 库，其他上游原生组件仍存在 RELRO 对齐缺口；尚不能列为全面兼容 16 KiB 设备。
