# 媒体下载 1.2.2

本次为图标与名称更新，版本代码 8。桌面名称改为“媒体下载”，首页继续使用“视频与图集下载”作为用途标题；页头、关于、诊断及系统分享中的应用名称统一。名称缩短为四个字，避免在启动器中被截断。

新图标以圆角方形为设计基础，适配 Android 自适应图标、旧版系统和单色主题。应用内标识同步更新，通知使用独立的小图标。

下载、图集选择、队列、设置和存储行为沿用 1.2.1，保持应用 ID `com.flowframe.app`、正式签名与 `FlowFrame` 媒体目录。手机安装包为 `arm64-v8a`，支持目标仍为 Android 7.0 及以上；同签名正式包可覆盖升级。

小红书、快手仍为试验性。原生组件剩余 RELRO 对齐缺口未在本轮解决，完整 16 KiB 兼容边界与 1.2.1 相同。旧版测试和性能结果见 [1.2.1 优化报告](../OPTIMIZATION-1.2.1.md)，不作为本轮重测结果。

本轮 104 项 JVM 回归通过；Release Lint 无错误，保留 4 项既有警告。手机 arm64 包和虚拟机 x86_64 包均构建成功，并通过原正式证书的 v2/v3 签名及 ZIP 对齐检查。

Android 7（API 24）与 Android 15（API 35）虚拟机覆盖安装、启动通过。旧系统应用抽屉中的圆角方形图标与完整桌面名称、现代系统自适应图标、应用内页头与关于页均已检查。API 35 从 1.2.1 / 7 升级至 1.2.2 / 8 后保留 8 条任务、并发 2、仅 Wi-Fi 设置和默认目录授权状态。单色图标完成矢量渲染预览；没有把预览当作所有手机主题桌面的实测。

桌面图标外轮廓会遵循手机启动器的形状设置：圆角方形桌面显示圆角方形，使用圆形图标的桌面显示圆形。核心图案保留在 Android 自适应图标的安全区域中。图标源码与生成方式见 [开发指南](../DEVELOPMENT.md)。

两种安装包的 7 个原生库外层条目和固定解析内核均与 1.2.1 逐字节相同。本轮没有重测全部站点下载流程，也不改变既有平台与原生组件的兼容结论。
