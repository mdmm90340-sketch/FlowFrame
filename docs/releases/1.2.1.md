# 视频与图集下载 · 流影 1.2.1

本次为本地结构与效率优化版，版本代码 7。保持原应用 ID 和正式签名，可覆盖原正式版；没有推送或创建 GitHub Release。

等待下载的任务改为接收名额和设置变化通知，不再每 250 毫秒轮询。历史存储在有变化时才调度写入，跳过同值更新，并保持完成、失败、取消立即保存；写入失败时保留待保存内容并延迟重试。

任务界面转换集中到独立模块，复用没有变化的行。输入、页面和预览选择使用单独的恢复快照，下载进度不会再触发草稿重复保存。原有用途标题、目录选择、选图、画质、取消/重试、打开/分享和删除记录行为保持。

签名、固定解析内核、原生库和平台能力范围均沿用 1.2.0。小红书、快手仍为试验性；原生组件剩余 RELRO 对齐缺口未在本轮解决，不能承诺全面兼容 16 KiB 手机。测试结果与性能测量范围见 [优化验收报告](../OPTIMIZATION-1.2.1.md)。
